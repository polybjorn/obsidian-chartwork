# Security policy

Please use GitHub's [private vulnerability reporting](https://github.com/polybjorn/obsidian-chartwork/security/advisories/new) rather than opening a public issue, or email security@polybjorn.com, encrypted with the key at https://polybjorn.com/pubkey.asc if the report holds anything sensitive. Either keeps the disclosure private until a fix is available.

Expect an initial response within a week. Only the latest released version receives fixes.
